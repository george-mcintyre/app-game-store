# Contributing

This repository does not accept outside contributions: pull requests from anyone outside
Level N Ltd are closed without review, so that the code has a single owner.

- Bug reports and ideas: open an issue.
- Security problems: report them privately at https://github.com/george-mcintyre/ourapps/security/advisories/new, never in a public issue.
- Questions about your data on ourapps.app: use the contact details on https://www.level-n.com.
